# Contributing

## Pull requests

For now, pull requests are only accepted from collaborators on this repository.

## Issues

Bug reports and feature requests are welcome in
[Issues](https://github.com/rootstring/set/issues).

## For collaborators

- Setup and commands: [docs/development.md](docs/development.md)
- Run the checks in [Tests](docs/development.md#tests) before opening a pull request.
- Keep each pull request to one change.
- Contributions are licensed under [AGPL-3.0](LICENSE).
